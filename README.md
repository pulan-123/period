# 课程表与作业管理

一个美观、功能完整的在线课程表与作业管理应用。

## 功能特性

- 📅 课程表展示
- 📋 作业管理（支持勾选完成）
- 🗑️ 拖拽删除作业
- 📸 图片 OCR 识别课程表
- 📝 文字/文档导入课程表
- ➕ 课程复制功能
- ➖ 课程删除功能
- 🔄 课程拖拽移动
- 💾 本地存储数据
- 🎨 精美 UI 与交互动效

## 使用说明

### 基本操作

1. **添加课程**：双击课程格子或使用导入功能
2. **删除课程**：点击课程上的 ➖ 按钮
3. **复制课程**：点击课程上的 ➕ 按钮
4. **移动课程**：直接拖拽课程卡片
5. **管理作业**：点击课程上的 📋 作业按钮

### 导入方式

- **图片 OCR**：上传课表图片自动识别
- **文字导入**：粘贴或上传文档导入
- **手动添加**：双击课程格子编辑

## 部署方式

### GitHub Pages 部署

1. 在 GitHub 上创建新仓库
2. 上传以下文件：
   - `index.html`（必须）
   - `README.md`（可选）
   - `.gitignore`（可选）
3. 进入仓库 **Settings** → **Pages**
4. Branch 选择 `main` 或 `master`
5. 点击 Save，等待 1-5 分钟即可访问

### 访问地址

部署后访问：`https://你的用户名.github.io/仓库名/`
