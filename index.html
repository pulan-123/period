📖 课程任务桌

课表展示 · 添加课上作业 · 完成打勾 ✔️

💡 提示：双击课程格子可编辑课程名称与地点（清空名称=删除课程并移除相关作业）
📌 每个课程右侧"作业"按钮可查看/添加/完成该课作业，作业支持打勾标记完成和删除。
🤖 AI导入课表：将这段话发给AI，并附上课表截图——"请认真识别图片，把所有课程写出来，不要漏，按照我给的格式，周数，节数，课程，教室" ，然后把AI生成的结果粘贴到「📝 文字导入」即可。
☁️ GitHub同步：点击「☁️ 同步」按钮可将课表数据保存到 GitHub 仓库，换设备也能恢复！
🔑 Token 需要 repo 权限：在 GitHub 设置 → Developer settings → Personal access tokens → 勾选 repo 下所有权限。
